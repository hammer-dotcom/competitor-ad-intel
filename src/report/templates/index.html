How it works

Four stages, one cron trigger, no human in the loop.
  1. Trigger. A weekly cron fires the run. No dashboard to remember to open.
  2. Collect. Public ad libraries are read per advertiser, then normalised into one schema so a new platform is one file, not a rewrite.
  3. Classify. Claude labels every creative against a fixed taxonomy — angle, offer, funnel stage, audience, proof used. Enum-constrained, so the labels can be trended instead of just read.
  4. Deliver. A branded PDF, a Slack digest, and this page. Runtime is treated as the performance proxy: an ad live 60 days is an ad that works.
Sources: Meta Ad Library, LinkedIn Ad Library — both public transparency surfaces. Classification by LLM; runtime is a proxy signal, not reported spend. Built with Python, Apify, Claude and WeasyPrint. Source
